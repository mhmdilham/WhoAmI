# WhoAmI (Siapa Gue?) - Web Minigame Tongkrongan 🎭

Web minigame tebak karakter/identitas tersembunyi yang dimainkan secara online via voice chat (Discord / WhatsApp / Google Meet) atau saat nongkrong langsung.

## 🎯 Gameplay & Mekanik Utama
- **Layar Jidat Digital:** Semua pemain bisa melihat kartu karakter pemain lain di layar, tetapi kartu miliknya sendiri tertutup (`???`).
- **Voice-Based Interaction:** Pemain bergiliran bertanya di Discord menggunakan pertanyaan tertutup (*"Apakah aku manusia?", "Apakah aku musisi?"*).
- **Web Sound FX & Buzzer:** Teman-teman merespons via tombol di web (*🟢 YA*, *🔴 TIDAK*, *🟡 BISA JADI*) dengan sound effect realtime.
- **Kategori Karakter:**
  - **Preset Deck:** Anime (Naruto), Pop Culture, Meme, dll.
  - **Custom Secret Deck:** Setiap pemain menuliskan 1 karakter rahasia untuk diacak menggunakan algoritma *Derangement* (dijamin tidak ada yang mendapat karakter buatannya sendiri).
